# Screenshot Manifest

All images are real Chrome (Playwright, channel chrome) screenshots of the running Vite dev server built from
`fix/flow-1-3-receptionist-concept-a-consolidated` at code commit `ccf05195` (ccf05195c3d8beef155b1f114c2b84b447fd9194).

**Dataset: FIXTURE (mock API).** No backend or database was used: the browser answered every `/api/v1` call
from fixture JSON with obviously fake people (`Fixture Member A`, `@example.invalid`). Unlisted calls returned 404
and would show the real error state; the final run had 0 unlisted calls. Real backend-connected screenshots are
NOT VERIFIED, because starting the backend would apply Flyway migrations to the local `sportify` database, which
has not been approved. No tokens, passwords or personal data appear in any image.

Role: RECEPTIONIST fixture session (fake token) except the Home reference (anonymous). Theme: light unless the
state says dark (browser color scheme dark, app preference system). All SHA-256 values are distinct.

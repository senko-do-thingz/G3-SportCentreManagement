## Attendance concepts and lifecycle boundaries

Arrival is a staff-created check_in row with ALLOWED or DENIED. It requires a current-day confirmed booking in this implementation. Booked participation is a CONFIRMED booking, created before training and debiting package balance once. Coach roster reads confirmed bookings for an assigned session. The self-training route returns an ACK without persistence. Coach-marked attendance would use separate training semantics, and historical attendance is a separate member read capability. None of these facts authorizes treating all five concepts as one event. EV-004 (`NX-01-evidence-index.md#ev-004` - local review reference, not published), EV-005 (`NX-01-evidence-index.md#ev-005` - local review reference, not published), EV-007 (`NX-01-evidence-index.md#ev-007` - local review reference, not published), EV-008 (`NX-01-evidence-index.md#ev-008` - local review reference, not published), EV-010 (`NX-01-evidence-index.md#ev-010` - local review reference, not published)

Session cancellation cancels confirmed bookings and restores capped credits only to ACTIVE registrations. Member cancellation refuses ALLOWED check-ins and applies the 120-minute cutoff. Future attendance must preserve existing lock order, avoid a second debit, define cancelled/late/absent/excused behavior and distinguish restoration from monetary refund.

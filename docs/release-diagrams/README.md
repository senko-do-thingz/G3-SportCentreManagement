# Sportify Final Release Diagrams

Editable Draw.io sources and SVG figures referenced by the SRD and Final Release Document. These files are maintained in the GitHub repository and are not mandatory attachments in the academic submission ZIP.

- Nine editable `.drawio` source files cover D-01 through D-11.
- Sixteen `.svg` figure exports correspond to report figures.
- The diagrams summarize the current desktop release, including VietQR integration, Gmail OTP recovery, Spori handoff, operational roles and Flyway migrations through V62.
- The diagrams cover the current business flows and intentionally omit archived-only workflows.
- `docs/database/Sportify_ERD.drawio` is an older schema snapshot labeled V1-V48. Do not treat it as a current physical-schema inventory; use Flyway migration SQL for complete table definitions.

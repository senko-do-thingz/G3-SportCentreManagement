## Role, route, inputs and execution modes

Default role: authorized synthetic MEMBER. Default route: `/member/payments/52/qr-demo`. Default input: ID 52, PENDING, DTO amount 810000 displayed as 810.000 VND. Amount-authority unit tests also use 731234. Negative roles are anonymous and receptionist; ownership/error cases use synthetic backend responses. No live backend or financial operation was used.

Vitest uses jsdom and existing fake fetch. Primary browser tests use real Microsoft Edge, actual Clipboard API, independent ZXing decoding and axe. Windows intermittently denied local asset HTTP requests; final browser runs used byte-identical compiled demo/standard assets fulfilled from disk, with synthetic API responses. Asset hashes and requests are recorded. Supplemental race/unsupported checks use explicit clipboard response fixtures in the real browser and are distinct from actual clipboard success/permission-denial checks.

The preexisting dependency files were backed up and remain byte-identical, unstaged and outside the PR. CODEOWNER authorization permits this branch in the primary checkout. No extra worktree/clone/reset/stash was used.
